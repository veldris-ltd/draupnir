# veldris-draupnir

**This package is a name reservation. It contains no code.**

DRAUPNIR is the CIM-56 model factory control plane, internal software of
Veldris. It is not distributed on the Python Package Index and this
distribution is not it. Installing this package gives you metadata and this
file; there is nothing to import.

## Why the name exists

The name `draupnir` on PyPI belongs to an unrelated project — an ancestral
sequence reconstruction tool — which was published first and is still
maintained. Because that name is taken, the Veldris control plane is
distributed internally as `veldris-draupnir`, and this reservation prevents
the name being taken by someone else.

If you were looking for the bioinformatics tool, you want
[`draupnir`](https://pypi.org/project/draupnir/), not this.

## If you are a Veldris engineer

You are in the wrong place. The control plane is installed from the internal
index or from the repository, never from PyPI. See `docs/PUBLISHING.md` in the
DRAUPNIR repository.
